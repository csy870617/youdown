youdown 은 컴퓨터(Mac·Windows)에서 사용하는 프로그램이에요.
이 링크를 컴퓨터에서 열어 주세요.

Mac 설치 방법

  1. 받은 youdown-mac.dmg 를 열고, youdown 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
  2. 응용 프로그램(또는 Launchpad)에서 youdown 을 실행해요.
  3. 처음 한 번은 "확인할 수 없음" 창이 떠요. 완료를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 "그래도 열기"를 누르세요.

    macOS 14 이하라면 youdown 을 Control+클릭 → 열기 로도 돼요. 서명 비용이 드는 인증을 받지 않은 앱이라 나오는 안내예요.

  4. 브라우저가 자동으로 열리면 끝! 처음 한 번만 필요한 준비(1~3분) 후 바로 쓸 수 있어요.

경고 없이 더 빠르게 추천

터미널(⌘+스페이스 → "터미널")에 아래 한 줄을 붙여넣고 Enter — 설치부터 실행까지 자동으로 끝나요. 보안 경고도 뜨지 않아요.

curl -fsSL https://raw.githubusercontent.com/csy870617/youdown/HEAD/scripts/install-mac.sh | bash

Windows 설치 방법

  1. 받은 youdown-setup.exe 를 실행해요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

    서명 비용이 드는 인증을 받지 않은 프로그램이라 나오는 안내예요.

  3. 설치가 끝나면 youdown 이 바로 실행되고 브라우저가 열려요. 다음부터는 바탕화면의 youdown 아이콘으로 실행하세요.

자주 묻는 질문

처음 실행할 때 왜 기다려야 하나요?

유튜브 영상을 받는 데 필요한 구성요소(약 200MB)를 처음 한 번만 자동으로 내려받아요. 보통 1~3분이면 끝나고, 다음부터는 바로 실행돼요.

어떻게 종료하나요?

브라우저 탭을 닫으면 10분쯤 뒤 자동으로 종료돼요. 다시 쓰려면 youdown 아이콘을 누르면 됩니다. 이미 켜져 있을 때 아이콘을 누르면 창만 다시 열려요.

새 버전은 어떻게 받나요?

이 페이지에서 다시 내려받아 설치하면 덮어쓰기로 업데이트돼요. 유튜브 변화에 대응하는 다운로드 엔진은 앱이 알아서 최신으로 유지해요.

삭제하려면?

Mac: 응용 프로그램에서 youdown 을 휴지통으로 옮기고, 홈 폴더의 숨김 폴더 .youdown 도 지우면 완전히 삭제돼요. Windows: 설정 → 앱에서 youdown 을 제거하세요.
