컴퓨터에서 열어 주세요

youdown 은 컴퓨터(Mac·Windows)에서 사용하는 프로그램이에요.
이 링크를 컴퓨터에서 열어 주세요.

Mac 설치 방법

약 1분
  1. 터미널을 열어요. ⌘ + 스페이스 를 누르고 터미널을 입력한 뒤 Enter
  2. 아래 명령을 복사해서 터미널에 붙여넣고 Enter
    curl -fsSL https://raw.githubusercontent.com/csy870617/youdown/HEAD/scripts/install-mac.sh | bash
  3. 설치가 끝나면 youdown 이 실행되고 브라우저가 자동으로 열려요. 처음 한 번만 준비(1~3분) 후 바로 쓸 수 있어요.
  4. 다음부터는 이 페이지의 youdown 실행 버튼이나 Launchpad·Spotlight(⌘+스페이스)에서 실행하세요.

보안 경고 없이 설치돼요. 설치는 한 번만 — 새 버전은 앱이 켜질 때 자동으로 업데이트돼요.

Windows 사용 방법

설치 과정 없음
  1. youdown-win.exe 다운로드가 시작돼요.

    브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 막으면 … → 유지를 눌러 주세요.

  2. 받은 파일(다운로드 폴더)을 더블클릭해서 실행해요.
  3. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

    서명 비용이 드는 인증을 받지 않은 프로그램이라 처음 한 번 나오는 안내예요.

  4. 브라우저가 자동으로 열리면 끝! 함께 뜨는 검은 창을 닫으면 youdown 이 종료돼요.
  5. 다음부터는 받은 파일을 다시 실행하거나, 이 페이지의 youdown 실행 버튼을 누르세요.

설치할 필요 없이 이 파일 하나로 실행돼요. 바탕화면에 옮겨 두면 편해요. 새 버전은 이 파일이 스스로 업데이트하니 다시 받을 필요 없어요.

자주 묻는 질문

처음 실행할 때 왜 기다려야 하나요?

유튜브 영상을 받는 데 필요한 구성요소(약 200MB)를 처음 한 번만 자동으로 내려받아요. 보통 1~3분이면 끝나고, 다음부터는 바로 실행돼요.

어떻게 종료하나요?

브라우저 탭을 닫으면 10분쯤 뒤 자동으로 종료돼요. Windows 는 함께 뜬 검은 창을 닫아도 돼요. 이미 켜져 있을 때 다시 실행하면 창만 다시 열려요.

새 버전은 어떻게 받나요?

따로 받을 필요 없어요. youdown 을 켤 때 새 버전이 있으면 자동으로 받아서 바꾸고, 이전 버전은 알아서 지워져요. 화면에 "업데이트 중"이 잠깐 보인 뒤 그대로 이어서 쓰면 됩니다.

삭제하려면?

Mac: 응용 프로그램에서 youdown 을 휴지통으로 옮기세요. Windows: 받은 youdown-win.exe 파일을 지우면 돼요. ('youdown 실행' 버튼용 연결 정보는 남아도 아무 영향이 없어요.) 앱이 받아 둔 구성요소는 홈 폴더의 숨김 폴더 .youdown 에 있으니 함께 지우면 완전히 삭제돼요.

저작권이 있는 콘텐츠는 정당한 권리 범위 내에서만 이용하세요.
개인적·합법적 용도 전용입니다.
